# 运河纠纷程序衔接引擎

面向平陆运河通航后四类争议（水上事故、船员劳资、船舶污染、货物运输）的
**线上线下一体后端引擎**：八家共建单位（海事、检察、司法行政、人社、调解组织、
劳动仲裁、商事仲裁、法院）一口受理、按争议类型与当事人选择生成可解释程序路径，
并在调解转司法确认、劳动仲裁、商事仲裁、诉讼之间进行**双向确认的正式交接**。

## 解决的关键问题

- **材料不重复提交**：受理时登记最小身份资料、管辖连接点、请求事项、证据封存摘要（仅存 sha256），
  一次入库按授权共享；移送以材料包摘要核对一致为签收前提。
- **程序不相互冲突**：路径版本化，改道（管辖异议成立、跨境送达插入）只新增版本，
  旧路径只读保留；跨单位推进必须经移送双向确认，未签收责任不转移。
- **时效不在转办途中耗尽**：移送待签收、管辖异议审查、跨境送达等待域外回证期间，
  法定期限自动中止，恢复后剩余额度不变，逐段留痕可核对。
- **重复立案识别但不误合并**：强指纹（主体+法律关系+请求事项）拦截重复立案；
  弱指纹（主体+争议类型）只关联不同请求的并行案件。
- **三类视图各守边界**：当事人只见自身案件进度；协同单位仅见获授权且不超保密级别的材料；
  监督人员可按任一节点核对停留时间、效力状态与下一责任方。

## 目录

- `src/domain/`：受控词表、四类争议的路径规则（可解释）、指纹、期限中止计算、时间约定。
- `src/storage/`：SQLite schema 与仓储；事件只追加。
- `src/services/engine.py`：用例编排（受理、选路、移送、撤回、和解、异议、跨境送达、视图）。
- `src/api.py` / `src/app.py`：HTTP 接口、Bearer 令牌三类角色鉴权、启动入口。
- `contracts/`：受理登记与外部事件交换字段示例。
- `docs/domain.md`：领域对象、状态语义与标识约定。
- `scripts/migrate.py`：建库与演示令牌；`scripts/smoke.py`：端到端冒烟。
- `tests/`：34 项单元/集成测试。

## 运行

```bash
make test       # 单元 + 集成测试
make migrate    # 初始化本地 SQLite（默认 data/app.sqlite3）并写入演示令牌
make run        # 启动服务，默认 :8080，健康检查 GET /health
python scripts/smoke.py http://127.0.0.1:8080   # 对运行中的服务走完整流程
```

配置通过环境变量传入：`DATABASE_PATH`、`PORT`。本地数据库文件不得提交。

## HTTP 接口（摘要）

| 方法 & 路径 | 身份 | 说明 |
| --- | --- | --- |
| `POST /api/cases` | 司法行政窗口 | 一口受理；自动重复立案预检，返回当事方访问令牌与可选路径 |
| `POST /api/cases/{ref}/routes` | 经办单位 | 依争议类型+当事人选择+事实标志生成可解释路径 |
| `POST /api/cases/{ref}/transfers` | 当前节点责任单位 | 发起移送并起算期限中止 |
| `POST /api/transfers/{trf}/respond` | 接收单位 | 签收（摘要一致）或拒收，恢复/退回 |
| `POST /api/cases/{ref}/withdraw` | 当事人/经办 | 撤回部分或全部请求（全撤则路径 void 留痕） |
| `POST /api/cases/{ref}/partial-settlement` | 调解/法院 | 部分和解；已和解项可转司法确认，其余继续 |
| `POST /api/cases/{ref}/jurisdiction-objection/file` | 当事人 | 提出异议，审查期间期限中止 |
| `POST /api/cases/{ref}/jurisdiction-objection/rule` | 裁判机构 | 驳回恢复原路径；成立则旧路径 superseded、生成新路径 |
| `POST /api/cases/{ref}/cross-border/start|complete` | 法院/商事仲裁 | 跨境送达期间持续中止，回证摘要到位后恢复 |
| `POST /api/cases/{ref}/stages/close` | 当前节点责任单位 | 同单位串行推进；跨单位强制先走移送 |
| `POST /api/events/ingest` | 共建单位 | 外部事件幂等接入，保留原始发生时间与同源序号 |
| `GET  /api/cases/{ref}` | 三类角色 | 当事人进度视图 / 单位授权材料视图 / 监督全量视图 |
| `GET  /api/supervision` | 监督人员 | 全部活动节点停留时间、超期标记、下一责任方、效力状态 |

演示令牌由 `make migrate` 打印（`tok-unit-*`、`tok-supervisor`）；
当事方令牌在受理响应中按 `party_ref` 返回。令牌仅用于演示联调，
生产环境须替换为统一身份设施签发并绑定自然人/岗位。
